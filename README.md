### 🎉 Birthday Surprise Website

A modern, premium birthday surprise website built using **HTML, CSS, and JavaScript**.  
Anyone can easily customize it by changing photos, music, and birthday details.

This project works as a **static website** and is perfect for:
- Sister / Brother birthday 🎂
- Friend birthday 🎉
- Loved ones 💖
- Surprise greeting pages ✨

---

## 🌟 Live Demo
After deployment (Vercel recommended), your site will look like a premium birthday card with:
- Animated background
- Countdown timer
- Music button
- Slideshow memories
- Confetti & hearts

---

## 🚀 Deploy on Vercel (vercel.app)

1. Push this project to GitHub
2. Go to https://vercel.com
3. Click **New Project**
4. Import your GitHub repository
5. Set:
   - Framework Preset: **Other**
   - Build Command: *(leave empty)*
   - Output Directory: *(leave empty)*
6. Click **Deploy**

Once deployed, Vercel will give you a live URL like:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)


## ✨ Features

- 🎂 Live birthday countdown (**IST timezone accurate**)
- 🎵 Background music (manual play – browser safe)
- 🎊 Confetti animation (Canvas)
- 💖 Floating hearts animation
- 🖼 Automatic photo slideshow
- 🎁 Surprise popup message
- 📱 Mobile-friendly & responsive
- 🌈 Premium glassmorphism UI
- ⚡ Fast & lightweight (no frameworks)
